Rules for every task: free tier only, no paid APIs, no new secrets, mocks + disabled flags for missing accounts (NEEDS-OWNER), additive migrations only, never touch the pharmacy repo, no deploys in tasks. Live app stays in local mode until the owner gates flip the flag.
`owner_gate` items are skipped by the scheduler; Nova runs them. Next phase depends on the previous phase's last code tasks, not on the gate.

## Backup policy (owner decision 2026-11-13, Asia/Riyadh)
Cloudflare R2 is **not** enabled: the dashboard requires a payment card, and the owner declined. Pending work must not add R2 bindings, R2 uploads, or R2-backed backups.
Operational backups (free, no card) are:
1. **D1 Time Travel** — built-in point-in-time restore within 30 days. Record a bookmark before every migration/deploy (`wrangler d1 time-travel info nova-rx-staging`). Data rollback = restore to that bookmark (owner-approved, in-place, staging first). See `docs/backend/BACKUP-RESTORE.md`.
2. **Daily encrypted GitHub artifact** — workflow `.github/workflows/d1-backup-staging.yml` runs `wrangler d1 export nova-rx-staging --remote`, gzip + OpenSSL AES-256-CBC (PBKDF2) encrypts with existing secret `NOVA_INGEST_SECRET`, and uploads only the ciphertext (retention 30 days). The repo is temporarily public, so artifacts are treated as world-readable (any GitHub user with repo read; third-party mirrors exist). Never upload plaintext SQL.
N106's Worker R2 helper remains in tree behind flag `NOVA_BACKUP` (default OFF). Staging has no R2 binding, so that path is a no-op. Do not extend it. Local/offline app backups stay in `backup-schedule.js` (OFF-04).
