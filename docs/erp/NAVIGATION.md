# تقسيم النظام للأقسام والصفحات (متفق عليه مبدئيًا)

مرجع: المحادثة مع المالك 9 نوفمبر 2026 · الخطة [ERP-1.0](../ERP_MASTER_PLAN.md) · الواقع [FND-01](FND-01_REALITY_MAP.md).

## الأقسام
| القسم | الصفحات |
|---|---|
| الرئيسية | ملخص اليوم، التنبيهات، المهام، حالة الفروع |
| البيع والكاشير | فاتورة بيع، مرتجعات، تعليق واسترجاع فاتورة، إغلاق الوردية، **الاستيكرات والتحذيرات وقت الصرف** |
| المخزون | الأصناف (وإعدادات السلامة الدوائية لكل صنف)، الأرصدة، التشغيلات والصلاحية، حركات المخزون، الجرد، التحويل بين المخازن، التالف والمرتجعات، **سجل تتبع الأدوية الخاضعة للرقابة**، **سجل تغييرات الأسعار** |
| المشتريات والموردون | النواقص، طلب شراء، عروض الموردين، سلة كل مورد، أمر شراء، استلام البضاعة، فواتير الموردين |
| العملاء | ملفات العملاء، المديونيات والتحصيل، سجل المشتريات، الولاء |
| المالية | الخزنة والبنوك، المصروفات، الإيرادات، مستحقات الموردين، التقفيل، الأرباح والتقارير المالية |
| الموارد البشرية | الموظفون، الحضور والانصراف، الورديات، الإجازات، الرواتب والسلف، الصلاحيات |
| الطلبات والتوصيل | طلبات العملاء، تجهيز الطلب، تعيين المندوب، متابعة التوصيل، حالات الطلب |
| التقارير والإدارة | تقارير المبيعات والمخزون والموظفين، مقارنة الفترات، مؤشرات الأداء |
| الإعدادات | الفروع والمخازن، المستخدمون والصلاحيات، الأجهزة، الربط والتكاملات، سجل التعديلات |

**السلامة الدوائية ليست قسمًا رئيسيًا:** بتظهر داخل البيع (الاستيكرات والتحذيرات) وإعداداتها ضمن الأصناف.

## قواعد العرض
1. **قائمة جانبية قابلة للطي:** بالعناوين لما تتفتح، وأيقونات فقط لما تتقفل؛ على شاشة البيع تتقفل لتوسيع الجدول (التابلت 1280×800).
2. **القسم غير الجاهز مايظهرش كوظيفة قابلة للاستخدام** (لا يظهر أو يظهر معطّل بعلامة «قريبًا» حسب قرار المالك). ممنوع أقسام فاضية.
3. **كل موظف يشوف الأقسام والوظائف المسموح له بيها حسب دوره** (SEC-02).
4. **نفس البيانات في كل الأقسام:** استلام أمر الشراء يزوّد الرصيد، والبيع يخصم منه، والفاتورة تسجّل حركة مالية؛ مفيش إدخال مكرر لنفس الصنف أو العملية.
5. **العملة:** جنيه مصري، والضريبة حسب تصنيف الصنف والقواعد المعتمدة، مفيش نسبة ثابتة (CAT-03).

## ترتيب الفتح (حسب بوابات الخطة)
- G0/G1: **البيع والكاشير** + **المخزون** (مع الأصناف والتشغيلات).
- G2: **المشتريات** + **العملاء** + **المالية**.
- بعدها: الطلبات والتوصيل، الموارد البشرية، التقارير.
- الأجزاء الموجودة في الداش بورد الحالي بتفضل فيه، ونحدد في FND-01 لكل جزء: يتربط أم يفضل.
