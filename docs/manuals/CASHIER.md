# دليل الكاشير

## بيع عادي
1. افتح شاشة البيع؛ أدخل اسمك إن طُلب.
2. أضف الأصناف بالبحث أو الباركود؛ عدّل الكمية (علبة/شريط).
3. الخصم: يتطلب اسم المعتمد.
4. اختر طريقة الدفع (نقدي/غيره) وأكّد؛ تُحفظ الفاتورة على هذا الجهاز **قبل** الطباعة/المشاركة.
5. اطبع أو شارك الإيصال (PDF) — الطابعة الحقيقية لم تُجرَّب بعد.

## مرتجع / إلغاء
افتح الفواتير ← اختر الفاتورة ← مرتجع أو إلغاء ← اكتب السبب. لا حذف: يُسجَّل المرتجع كحركة.

## البيع الطارئ (دون اتصال)
صفحة `emergency-sales.html`: تعمل بلقطة أسعار محمّلة مسبقاً. الفاتورة **مؤقتة** وتحمل عبارة «لم تُرحَّل للنظام». انتبه لشريط تحذير عمر اللقطة (أكثر من 6 ساعات = قديمة).

## تنبيهات
- لا تمسح بيانات المتصفح: الفواتير محلية.
- لا تُدخل أي أرقام سرية في خانات الملاحظات.
