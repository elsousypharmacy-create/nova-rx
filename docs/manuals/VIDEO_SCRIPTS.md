# سيناريوهات الفيديو القصيرة

**لم يُسجَّل أي فيديو.** تسجيل الشاشة يحتاج جهازاً حقيقياً ونسخة منشورة؛ هذا الملف جاهز للتسجيل (30–90 ثانية لكل مهمة، دون بيانات عملاء حقيقية، على نسخة المعاينة).

| # | العنوان | الخطوات |
|---|---|---|
| 1 | بيع سريع | بحث ← إضافة صنف ← كمية ← دفع ← إيصال |
| 2 | مرتجع | الفواتير ← فاتورة ← مرتجع ← سبب |
| 3 | بيع طارئ | تحميل اللقطة ← إضافة ← فاتورة مؤقتة PDF |
| 4 | صلاحية ودفعات | شاشة الدفعات ← فرز بالأقرب ← تحذير |
| 5 | مقارنة موردين | purchases ← بحث ← مقارنة (قراءة فقط) |
| 6 | تقرير اليوم | التقارير ← إجمالي ← مرتجعات |
| 7 | ملصق رف | sticker-studio ← اختيار ← معاينة ← طباعة |

شروط التسجيل: اتجاه RTL ظاهر، عملة ج.م، لا أرقام سرية على الشاشة، حفظ الملف مع تاريخ ورقم الإصدار (SHA).
