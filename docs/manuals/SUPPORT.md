# دليل الدعم الفني

## أسئلة تشخيص سريعة
| العرض | الفحص |
|---|---|
| الأسعار قديمة/غائبة | عمر اللقطة؛ حدّث الصفحة وهي متصلة؛ تحقق من `/emergency/stock.json` |
| فاتورة اختفت | هل مُسحت بيانات المتصفح؟ هل المزامنة مفعّلة على الجهاز؟ لو مقفولة فالتخزين محلي فقط |
| «في انتظار المزامنة» لا تنتهي | النت؟ الجهاز مسجّل دخول؟ رصيد الصنف موجود على الخادم؟ |
| «فواتير تحتاج ضبط الوحدة» | سجّل تعبئة الصنف (شرائط/أقراص) وهي تتبعت لوحدها |
| نص إنجليزي/اتجاه خاطئ | سجّل لقطة شاشة؛ يجب أن تكون الواجهة عربية RTL |
| الصفحة بيضاء على الموبايل | انظر pharmacy#59؛ جرّب تحديثاً كاملاً وبلّغ بنوع الجهاز |
| الطابعة لا تعمل | لم تُجرَّب طابعة حقيقية؛ سجّل الطراز والمتصفح |

## ما يُجمع في البلاغ
الجهاز والمتصفح، الصفحة، الخطوات، الوقت، لقطة شاشة **دون بيانات عملاء أو أسرار**.

## حدود الدعم
لا تطلب ولا تقبل كلمات سر أو مفاتيح في المحادثة أو GitHub. النشر، المورّدون، الدفع: للمالك فقط.

## مسار الدعم المختصر
1. صوّر الشاشة كلها (ومعها علامة المزامنة والوقت ظاهرين).
2. اكتب: عملت إيه، كنت متوقع إيه، وحصل إيه.
3. ابعتها للمالك (أحمد) أو لمسؤول الدعم المعتمد.
4. **ممنوع تمامًا** إرسال أو لصق أي رقم سري (PIN) أو كلمة مرور أو توكن أو مفتاح لأي شخص، حتى الدعم.
5. لا تجرّب الإرسال لعملاء حقيقيين على واتساب أثناء الدعم.
