# دليل الدعم الفني

## أسئلة تشخيص سريعة
| العرض | الفحص |
|---|---|
| الأسعار قديمة/غائبة | عمر اللقطة؛ حدّث الصفحة وهي متصلة؛ تحقق من `/emergency/stock.json` |
| فاتورة اختفت | هل مُسحت بيانات المتصفح؟ هل هو نفس الجهاز/المتصفح؟ (التخزين محلي) |
| نص إنجليزي/اتجاه خاطئ | سجّل لقطة شاشة؛ يجب أن تكون الواجهة عربية RTL |
| الصفحة بيضاء على الموبايل | انظر pharmacy#59؛ جرّب تحديثاً كاملاً وبلّغ بنوع الجهاز |
| الطابعة لا تعمل | لم تُجرَّب طابعة حقيقية؛ سجّل الطراز والمتصفح |

## ما يُجمع في البلاغ
الجهاز والمتصفح، الصفحة، الخطوات، الوقت، لقطة شاشة **دون بيانات عملاء أو أسرار**.

## حدود الدعم
لا تطلب ولا تقبل كلمات سر أو مفاتيح في المحادثة أو GitHub. النشر، المورّدون، الدفع: للمالك فقط.
