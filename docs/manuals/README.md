## ما هو مبني فعلاً وما ليس كذلك
- يعمل (على نسخة المعاينة nova-rx-preview): قائمة الأسعار الحقيقية، البيع وحفظ الفاتورة على نفس الجهاز، المرتجع/الإلغاء، الفواتير والتقارير من الفواتير المحفوظة، العملة ج.م، صفحة المشتريات، استوديو الملصقات، صفحة البيع الطارئ.
- **غير مجرَّب:** طابعة حقيقية، تابلت حقيقي، أوامر شراء حقيقية من المورّدين.
- لا يوجد خادم/قاعدة بيانات دائمة بعد (مجمّد حتى انتهاء تجربة الواجهة). الفواتير تُحفظ على الجهاز فقط: مسح بيانات المتصفح يحذفها.
- الشاشات الموصوفة قد تتغير؛ حدّث الدليل مع كل تعديل واجهة.
