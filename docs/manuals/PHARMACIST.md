# دليل الصيدلي

## المهام الأساسية
1. **البحث عن دواء:** اكتب الاسم (عربي/إنجليزي) أو امسح الباركود. تظهر النتائج فوراً مع السعر (ج.م) والمخزون التقريبي.
2. **التحقق من البدائل والجرعات:** افتح بطاقة الصنف؛ راجع العبوة/الوحدات (علبة/شريط) قبل الصرف.
3. **تحذيرات الأدوية:** إن ظهر تحذير تداخل أو حساسية فاقرأه قبل المتابعة؛ القرار الدوائي لك وليس للنظام.
4. **الصلاحية:** راجع شاشة الدفعات والصلاحية؛ لا تصرف دفعة منتهية أو مسحوبة (recall).
5. **الروشتة:** سجّل بيانات الروشتة ومتابعة المريض حسب الشاشة المتاحة.

## قواعد
- المخزون المعروض تقريبي وليس لحظياً؛ تأكد من الرف عند الشك.
- لا تعدّل سعراً أو خصماً دون اسم المعتمد.
- أبلغ الدعم عن أي سعر يبدو خاطئاً مع اسم الصنف ووقت المشاهدة.
