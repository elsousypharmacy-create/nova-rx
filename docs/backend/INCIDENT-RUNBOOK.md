# دليل الحوادث — NOVA Rx (Incident runbook)

## 1. التصنيف
- **P0**: توقف البيع أو فقدان/تلف بيانات أو تسريب. **P1**: ميزة رئيسية معطّلة. **P2**: خلل جزئي.

## 2. الخطوات
1. **إيقاف النزيف**: عطّل علم الميزة للمستأجر المتأثر (`POST /api/v1/flags` مع `enabled:false`) أو اضبط `rolloutPct` إلى 0. التطبيق المحلي يعمل دون الخادم دائماً (وضع محلي).
2. **التحقق**: `GET /api/v1/version` و`GET /api/v1/health`، وراجع `X-Request-Id` من رسالة الخطأ.
3. **التراجع**: انظر `ROLLBACK.md` (نسخة Worker السابقة)؛ المستأجر يُعطَّل برفق عبر `/api/v1/onboarding/disable` ولا تُحذف صفوف.
4. **البيانات**: لا حذف ولا ترحيل مدمّر؛ الاستعادة وفق `BACKUP-RESTORE.md`.
5. **التواصل**: سجّل الحادث في Issue #87 (المعرّف، الأثر، الإجراء، الحالة). لا تضع أسراراً أو بيانات عملاء.
6. **المراجعة بعد الحادث**: السبب الجذري، اختبار يمنع التكرار، تحديث `CURRENT.md`.

## 3. التشخيص (اختياري)
يُرسل فقط إذا فعّله المالك (`/api/v1/diagnostics/optin`). الحقول المسموحة: `kind` (error|perf|sync)، `code`، `appVersion`. لا نص حر ولا معرّفات ولا بيانات مرضى أو عملاء.

## 4. إجراءات المالك فقط
فتح عملية مورّد مجهولة، نشر الإنتاج، حذف مدمّر، الأسرار والمدفوعات.
